# 小茉（xiaomoAgent）

陪伴型 Agent。设计目标只有一句话：**她记得住事，也会主动找你。**

Windows 桌面应用（Tauri 2 打包），手机浏览器也能直接访问。后端零依赖（Node 自带的 `node:sqlite` + `node:http`），聊天记录、记忆与模型密钥全部留在本机。

## 能做什么

### 对话

- **多联系人**：每位有独立的会话、相处设定与记忆，互不串味
- **流式回复**：边生成边显示；长回复按句拆成多个气泡逐条出现，Markdown（列表 / 代码块 / 表格）整条不拆
- **工具过程卡**：她查时间、翻记忆、立提醒、画图时，过程以卡片出现在对话流里，不是黑箱
- **消息操作**：右键（手机长按）可复制 / 编辑 / 撤回 / 删除
- **附件与媒体**：发图给她看（图片理解）、语音输入（语音识别）、回复可朗读（语音合成）
- **对话地图**：长会话按轮次快速跳转
- **手机可用**：窄屏是「消息列表 → 全屏会话」的两级流，支持添加到主屏幕

> 有意区分：**改一句消息 ≠ 改记忆**。改了话不会连带抹掉她记下的事——要动记忆去记忆页动。

### 关系与记忆

- **长期记忆**：对话里发生的事沉淀成「关系事件」，按联系人隔离，每条带发生时间
- **记忆召回**：注入上下文时带披露外壳与字符预算，模型看到的是"她想起的事"而不是命令；状态页有召回试验台，能看到这次为什么想起这条
- **记忆可维护**：编辑 / 删除 / 手动新增；定期整理会把记重的合成一条、翻篇的标成过期
- **窗口边缘梗概**：更早的对话压成一句「上次说到」，接得住「那件事后来呢」
- **关系温度计**：亲密度与心情随聊天变化，她说话的语气也跟着变
- **生活线摘要**：定期总结一段「最近的生活」，让她说话不显得没有生活

### 主动性

- **到点提醒**：说一句「明晚九点提醒我吃药」，到点原样发出去
- **主动关心任务化**：什么时候找你、说什么，落成可查、可取消、可顺延的任务，不是随机冒泡
- **不会烦到你**：免打扰时段 + 每日上限（全局可配，按联系人可覆盖），每位联系人还有独立的「允许主动触达」开关

### 能力（每项可单独接模型）

图片理解 · 图像生成 · 语音识别 · 语音合成 · 记忆抽取与整理 —— 每张能力卡都能单独配端点与模型，留空则跟随主模型。

- **联网**：搜公开网页、读网页正文（带内网地址拦截与内容相关性筛选）。这是唯一会主动向外发请求的能力，默认关闭
- **技能**：把做法说明书写成 `skills/<名字>/SKILL.md` 放进数据目录，她按需加载，可随时启停
- **微信 / QQ 通道**：微信走 iLink 机器人、QQ 走开放平台机器人；应用里她说的每句话会镜像到绑定平台，平台上发来的消息进同一段对话
- **问助手**：Ctrl / Cmd + K 召唤，能直接改配置、建联系人、换头像、排查问题

### 数据与用量

- **本地优先**：聊天记录、记忆、媒体、密钥都在本机 `data/` 目录；模型自备（任何 OpenAI 兼容服务），密钥不离开这台机器
- **用量可见**：每轮调用的耗时、token 与成本；可按用途（回消息 / 记忆整理 / 主动判断 / 通道投递）筛

## 环境要求

- **Node.js ≥ 22.18** —— 用到 `node:sqlite` 与原生 TypeScript 类型擦除，后端脚本一律带 `--experimental-sqlite`
- 桌面开发 / 打包额外需要：**Rust 工具链** + **Tauri CLI**（`cargo install tauri-cli --version "^2"`）

## 快速开始

```bash
npm install
npm --prefix frontend install
cp .env.example .env        # Windows: Copy-Item .env.example .env
npm run dev                 # 打开 http://127.0.0.1:8787
```

默认 `MODEL_MODE=echo`：本地假回复，不花钱、不依赖网络，用来先把界面与记忆链路跑通。

### 接入真实模型

两种方式，都能改、保存即生效：

1. **应用内改（推荐）**：<http://127.0.0.1:8787/settings> →「主对话模型」/「能力模型」，填 Base URL、API Key、模型名，可点「测试连接」实测
2. **改 `.env`**：`MODEL_BASE_URL` / `MODEL_API_KEY` / `MODEL_NAME`

应用里改的值存在数据库，优先级高于 `.env`；`.env` 只给"没在界面上配过"的情况兜底。

## 常用命令

| 命令 | 作用 |
| --- | --- |
| `npm run dev` | 浏览器里跑，改后端自动重启（<http://127.0.0.1:8787>） |
| `npm run app` | 桌面窗口里跑（Tauri），前端热更新 |
| `npm run check` | 类型检查（后端 + 前端） |
| `npm run doctor` | 环境与配置自检，会列出服务商可用模型并逐个实测 |
| `npm run smoke` | 全链路冒烟（离线 echo 模式，780+ 断言） |
| `npm run desktop:build` | 打 Windows 安装包（需自备 Tauri 更新签名私钥） |
| `npm run release` | 出包 + 发 GitHub Release（含 `latest.json`，应用内自动更新用它） |
| `npm run ver` | 版本号唯一入口：`npm run ver` 查看/校验，`npm run ver patch` 递增 |

## 目录结构

```
src/            后端：Agent 循环、记忆、主动性、通道、设置（零依赖 TS）
frontend/       前端：Vite + React + TS
shared/         前后端共用的类型定义
src-tauri/      Tauri 2 桌面外壳（Rust）
scripts/        构建、打包、校验与冒烟测试
data/           运行时数据（聊天记录 / 记忆 / 媒体 / 密钥），不入库
```

## 安全须知

- **所有 `/api/*` 都没有鉴权**。默认只监听 `127.0.0.1`；直接把服务暴露到公网等于公开聊天记录。需要公网访问请自己加鉴权，或只在可信隧道之后使用（隧道域名要写进 `TRUSTED_HOSTS`，否则会被主机守卫 403）
- 聊天记录、记忆、模型 API Key 都保存在本机 `data/`（默认 `./data/xiaomo.db`）
- `DEV_MODE=1` 会把模型请求原文（含系统提示词）暴露给界面，只用于本地排查
- 桌面安装包对后端资源做完整性校验；被误删或被杀软隔离时，可在 `%APPDATA%\app.xiaomo.ai` 下建一个 `allow-unsigned` 空文件跳过校验（删掉即恢复严格模式）
